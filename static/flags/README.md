A flag is a representative country or region for a language, not its sole owner.
The catalog keeps regional flags where available, including Welsh, Scottish Gaelic,
Basque, Catalan and Galician. Detect language keeps the existing auto.svg globe.
Language choices and their flag mappings are in ../language-catalog.json.
Run .venv/bin/python scripts/setup_flags.py to restore these assets.
