# คู่มือการใช้งาน TH AI Translator

## เริ่มแปลใน 3 ขั้นตอน

1. เลือกภาษาต้นทางและปลายทางที่แถบด้านบน (กดชื่อภาษาเพื่อค้นหา หรือกด ⇄ เพื่อสลับ)
2. พิมพ์หรือวางข้อความ ระบบจะแปลให้เองเมื่อหยุดพิมพ์ (หรือกด Ctrl/⌘ + Enter)
3. คัดลอก 📋 ฟังเสียง 🔊 หรือกดดาว ⭐ เพื่อเก็บไว้ในรายการโปรด

## โหมดต่าง ๆ (แถบด้านล่าง)

| โหมด | ใช้ทําอะไร | เคล็ดลับ |
|---|---|---|
| ข้อความ | แปลข้อความไม่เกิน 5,000 ตัวอักษร | กดไมค์เพื่อพูดแทนการพิมพ์ |
| รูปภาพ | แปลเมนู ป้าย เอกสารบนรูป และวางคําแปลทับตําแหน่งเดิม | อ่านรายการคำแปลใต้รูปได้ทันที แตะรายการเพื่อคัดลอกหรือฟังเสียง กดเต็มจอเพื่อขยายรูป |
| เอกสาร | TXT, CSV, Markdown, PDF (ไม่เกิน 20 หน้า), DOCX | บนมือถือสลับแท็บต้นฉบับ/คำแปลเพื่ออ่านเต็มพื้นที่ กดชื่อไฟล์เพื่อเปลี่ยนเอกสาร |
| แชทสด | คุยกันสองภาษา แต่ละฝั่งมีไมค์ของตัวเอง | เปิด “ตรวจข้อความจากไมค์ก่อนส่ง” ถ้าต้องการแก้ก่อนส่ง |

การแปลเอกสารแสดงเป็นข้อความ ไม่คงรูปแบบหน้า PDF/DOCX เดิม

## ภาษาไทยพูด สแลง และภาษาถิ่น

ใต้ตัวเลือกภาษาจะมี **ตีความภาษาไทย** ให้เลือก สแลง / เหนือ / อีสาน / ใต้ หรือ “ไม่แน่ใจถิ่น” ระบบจะแสดงความหมายเป็นภาษาไทยกลางคู่กับคําแปล ถ้าความหมายยังกํากวม ระบบจะถามก่อนแปล คําที่ใช้บ่อยเพิ่มเองได้ที่ ⋮ → คลังสแลงและความหมายภาษาถิ่นของฉัน

หากไมค์สะกดสแลงหรือชื่อเฉพาะผิด ให้เลือกภาษาต้นทางเป็นไทย แล้วเพิ่มคำที่ต้องการในคลังสแลงหรือ My terminology ของโหมดนั้น แอปจะใช้เป็นคำศัพท์ช่วยถอดเสียงด้วย โดยไม่เปลี่ยนคำที่ได้จากเสียงเอง เมื่อมีข้อความแจ้งว่าเสียงไม่ชัด ให้ตรวจและแก้ก่อนกดส่ง การเพิ่มคำศัพท์ช่วยสะกดได้แต่ไม่รับประกันว่าจะถอดถูกทุกครั้ง

## ตรวจทานคําแปลสําคัญ

ใต้คําแปลมีเครื่องมือให้กดได้โดยตรง:

- **ทําไมแปลแบบนี้?** อธิบายว่าทําไมเลือกคํานี้
- **ตรวจคําแปล** ตรวจความหมายและความเป็นธรรมชาติ พร้อมคําแปลที่เสนอให้แก้
- **วิเคราะห์เชิงลึก** แปลกลับ ตรวจความกํากวม และเทียบคําแปล A/B

ป้าย “มีจุดที่ควรทบทวน” จะขึ้นเมื่อพบว่าตัวเลข ลิงก์ หรือคําเฉพาะไม่ตรงกับต้นฉบับ ข้อความเรื่องสุขภาพ กฎหมาย หรือการเงินควรให้คนที่รู้ภาษาตรวจซ้ําทุกครั้ง

## เมนู ⋮

- **การแปล:** สไตล์ (ธรรมชาติ ทางการ กันเอง ฯลฯ) บริบท (ร้านอาหาร ท่องเที่ยว พบแพทย์ ฯลฯ) และแปลพร้อมกันได้อีกสูงสุด 3 ภาษา
- **ประวัติและรายการโปรด:** เก็บอัตโนมัติในเบราว์เซอร์นี้ โหมดละ 100 รายการ ไม่ซิงก์ข้ามเครื่อง
- **การแสดงผล:** เปลี่ยนภาษาของแอปและธีมสว่าง/มืด
- **My terminology:** กําหนดคําแปลเฉพาะ เช่น ชื่อสินค้าหรือศัพท์งาน

## ติดตั้งเป็นแอปและใช้ตอนเน็ตไม่ดี

- **Android/Chrome:** เมนูเบราว์เซอร์ → ติดตั้งแอป / Add to Home screen
- **iPhone/Safari:** ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

แอปที่ติดตั้งแล้วจะเปิดได้แม้ไม่มีเน็ต แต่**การแปลยังต้องใช้อินเทอร์เน็ต** ถ้าออฟไลน์จะมีแถบแจ้งเตือนขึ้น ระหว่างนั้นยังเปิดดูประวัติและรายการโปรดที่เคยบันทึกไว้ได้

## ข้อจํากัดที่ควรรู้

- คําแปลมาจาก AI จึงผิดได้ โดยเฉพาะสํานวนที่ไม่คุ้น ชื่อเฉพาะ และภาษาที่มีข้อมูลน้อย
- ถ้าบริการ AI ถึงขีดจํากัดการใช้งาน ให้รอตามเวลาที่แจ้งแล้วลองใหม่
- รูปที่ตัวอักษรเล็ก เบลอ หรือใช้ฟอนต์ตกแต่งอาจอ่านผิด
- การถอดเสียงสําเนียงถิ่นยังไม่ได้ฝึกเฉพาะ ควรตรวจข้อความก่อนส่ง
- ข้อความ รูป และเสียงถูกส่งไปยังผู้ให้บริการ AI เพื่อประมวลผล อย่าใส่ข้อมูลลับ
