# Dialect reference data

`curated.json` contains short lexical facts with source attribution. They are
contextual references, not automatic replacements for complete sentences. Spelling
aliases are application normalization choices and are marked separately.

User-supplied meanings are explicitly marked `provenance: project_user_definition`
and have no claimed public sources. The slang expression `สาดไปสมาชิก` uses the
project user's explanation (acceptance/encouragement, such as `ลุยเลย`). This is
contextual guidance for generation and review, including Standard translation,
not a rule mapping every occurrence of `สาด` or `สมาชิก` to slang. Quoted discussion,
negation and literal contexts must retain their original meaning. Adding this
entry does not establish coverage of other modern slang or train the model.

Entries marked `editorial_context_note` are application-maintained contextual
language notes, not published dictionary attestations or model training. Their
literal and figurative readings must be resolved from the full source. They were
added after inspecting the development failures in `reports/slang-100/`; the same
examples therefore measure regression, not generalization. Source URLs are supplied
only where a specific external source was actually checked. English examples are
editorial suggestions, not unique required translations. A source URL does not
verify every English suggestion, literal contrast or usage restriction in a note.

Retrieval keeps up to eight distinct expressions and suppresses shorter overlapping
components. Patterns avoid obvious substring collisions such as เมนู/คอมเมนต์/โดเมน
and สับสน/สับปะรด. Context notes reach Standard translation, semantic review,
explicit Thai interpretation, per-label photo translation and assistant features.
Updating this file invalidates text/photo/source-info result keys; OCR results
remain independent of lexical guidance. No request's context is stored globally.

The optional local corpus index is generated by:

```bash
.venv/bin/python scripts/setup_dialect_references.py
```

Source: Thai Local Language Translation Dataset v1, Wannaphong Phatthiyaphaibun,
2024-08-09, https://doi.org/10.5281/zenodo.13283454.
The publisher identifies the dataset license as CC BY-SA 4.0:
https://creativecommons.org/licenses/by-sa/4.0/.
Based on Thai Dialect Corpus (Suwanbandit et al., INTERSPEECH 2023).

The script preserves source/translation pairs, removes duplicate pairs and adds
normalized keys/trigrams for retrieval. This generated adaptation and its data
remain under CC BY-SA 4.0; attribution and source URLs are stored with every result.
The downloaded CSV and SQLite index stay in `.data/dialects/` and are not bundled
into the application's code license or uploaded automatically to GitHub.

Important scope: Khummuang is used for Northern Thai. Korat is not relabeled Isan,
and Pattani is not relabeled generic Southern Thai. The current Northern retrieval
route only queries Khummuang. Auto mode can retrieve exact matches from explicitly
named varieties; no approximate cross-variety matching is performed. The corpus
contains noisy spellings and translations and is reference material, not verified
truth for every sentence. Examples are never silently substituted for the input.
