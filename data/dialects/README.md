# Dialect reference data

`curated.json` contains short lexical facts with source attribution. They are
contextual references, not automatic replacements for complete sentences. Spelling
aliases are application normalization choices and are marked separately.

User-supplied meanings are explicitly marked `provenance: project_user_definition`
and have no claimed public sources. The slang expression `สาดไปสมาชิก` uses the
project user's explanation (acceptance/encouragement, such as `ลุยเลย`). This is
contextual guidance for generation and review, including Standard translation,
not a rule mapping every occurrence of `สาด` or `สมาชิก` to slang. Quoted discussion,
negation and literal contexts must retain their original meaning. Adding this
entry does not establish coverage of other modern slang or train the model.

Entries marked `editorial_context_note` are application-maintained contextual
language notes, not published dictionary attestations or model training. Their
literal and figurative readings must be resolved from the full source. They were
added after inspecting the development failures in `reports/slang-100/`; the same
examples therefore measure regression, not generalization. Source URLs are supplied
only where a specific external source was actually checked. English examples are
editorial suggestions, not unique required translations. A source URL does not
verify every English suggestion, literal contrast or usage restriction in a note.

Retrieval keeps up to eight distinct expressions and suppresses shorter overlapping
components. Patterns avoid obvious substring collisions such as เมนู/คอมเมนต์/โดเมน
and สับสน/สับปะรด. Context notes reach Standard translation, semantic review,
explicit Thai interpretation, per-label photo translation and assistant features.
Updating this file invalidates text/photo/source-info result keys; OCR results
remain independent of lexical guidance. No request's context is stored globally.

## Interpretation reliability

The Southern Thai entries for ผรื่อ/พรื่อ/พรือ, แหลง and หรอย, and the Isan
entry for เว้า/เว่า/เหว้า include checked Wiktionary attribution (CC BY-SA 4.0).
Definitions are paraphrased; construction guidance is editorial, not a claim that
every full sentence has a unique dictionary translation. Literal meanings,
negation and user clarification still take precedence. Unverified suggestions
from model output are not added as established dictionary facts.

The reported `พันพรือมั่ง` case has a construction-level note for `พันพรือ`,
with application aliases `พันพรื่อ`/`พันผรื่อ`. Longdo's Southern Thai entry supports
its how-sense but is explicitly **user-contributed and unapproved**. The check-in
reading, colloquial มั่ง/บ้าง guidance and English examples are editorial; they
are not independently verified dictionary translations of the full sentence.
Explicit topics (work, symptoms, manner), negation and private meanings retain
precedence. Mocked tests verify retrieval and API plumbing, not actual model
translation accuracy. The model is instructed not to treat retrieved entries as
an exhaustive vocabulary or split a matching construction into unrelated words.

Retrieval normalizes equivalent sara-am encodings without removing tone marks,
selects overlapping references by actual occurrences, and rejects attached-mark
substring collisions. It does not use fuzzy spelling similarity as evidence.
Rebuild an existing optional corpus index after changing normalization so its
stored keys follow the same rules.

Interpretation can repair a schema/source-quote validation failure once; repeated
invalid output still fails. Equivalent Thai quote encodings are accepted, but
changed words or tone marks are not. A repair can return needs_context and does
not force unknown meanings into translations. Missing subjects alone should not
trigger clarification when neutral wording preserves the meaning. These rules
and mocked regression tests are not a real-provider dialect accuracy benchmark.

The optional local corpus index is generated by:

```bash
.venv/bin/python scripts/setup_dialect_references.py
```

The script preserves source/translation pairs, removes duplicate pairs and adds
normalized keys/trigrams for retrieval. This generated adaptation and its data
remain under CC BY-SA 4.0; attribution and source URLs are stored with every result.
The downloaded CSV and SQLite index stay in `.data/dialects/` and are not bundled
into the application's code license or uploaded automatically to GitHub.

Important scope: Khummuang is used for Northern Thai. Korat is not relabeled Isan,
and Pattani is not relabeled generic Southern Thai. The current Northern retrieval
route only queries Khummuang. Auto mode can retrieve exact matches from explicitly
named varieties; no approximate cross-variety matching is performed. The corpus
contains noisy spellings and translations and is reference material, not verified
truth for every sentence. Examples are never silently substituted for the input.

`northern-first-person-ha` addresses the reported first-person ฮา → laughter error.
Its `only_modes: ["northern"]` requires an explicit Northern selection, and its
predicate-position pattern avoids repeated laughter, standard-Thai funny/laughing
contexts and unrelated words. The lexical fact is sourced; the predicate matching
and English guidance are editorial scope restrictions. It is not a fixed
sentence replacement and does not infer gender or add profanity.

The interpretation path retries an invented laugh once, then rejects repeated bad
output. Explicit source laughter, private definitions and speaker clarification
retain precedence. Source alternatives use the same contextual guard. Changing
curated data invalidates backend text/source-info cache identities; refresh an
existing browser session to discard its older in-memory suggestions.

The real-provider regression run is in `reports/northern-ha-regression.json`.
The original phrase reached the model unchanged and produced first-person Central
Thai and English without laughter. This is one reported-case check, not a dialect
accuracy benchmark. Optional independent Gemini review was unavailable during
that run, so it is not claimed as an independently checked translation.
