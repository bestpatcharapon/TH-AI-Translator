# TH AI Translator

เว็บแอปแปลภาษา Flask + Groq มีตัวเลือกแปลข้อความ 113 ภาษา พร้อมหน้าจอมือถือและเดสก์ท็อป

## เริ่มใช้งาน

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/setup_ocr.py  # Ubuntu/Debian: ติดตั้ง OCR สำหรับแปลทับบนภาพ
cp .env.example .env
# ใส่ GROQ_API_KEY ใน .env
python app.py
```

เปิด http://127.0.0.1:5000 หากมี `.env` อยู่แล้ว ให้เก็บค่าของคุณไว้และเพิ่มเฉพาะตัวแปรที่ต้องการเปลี่ยน ค่าโมเดลภาพและเสียงมีค่าเริ่มต้นให้แล้ว

## Deploy บน Vercel

ใช้ Root Directory เป็นรากโปรเจกต์ที่มี `app.py` และตั้ง Install Command / Output Directory เป็นค่าเริ่มต้น ไฟล์ `vercel.json` เลือก Flask และเรียก `scripts/build_vercel.py` เพื่อคัดลอก UI ไป `public/static` ให้ CDN เสิร์ฟที่ URL เดิม รายการแพ็กเกจสำหรับเริ่มเว็บอยู่ใน `[project].dependencies` ของ `pyproject.toml` และระบุ Python 3.12 ไว้แล้ว เพิ่ม `GROQ_API_KEY` และค่าที่ต้องการใน Environment Variables ของ Vercel แล้ว deploy จาก commit ใหม่

ถ้าพบ `ModuleNotFoundError: No module named 'flask'` ให้ตรวจ Build Logs ว่าอ่าน `pyproject.toml` ฉบับที่มี dependencies แล้ว และ Redeploy โดยไม่ใช้ build cache เดิม การมีแค่ `[tool.ruff]` ในไฟล์นี้อาจทำให้ตัวติดตั้งเลือก manifest ที่ไม่มีแพ็กเกจ แม้ `requirements.txt` จะมี Flask อยู่

ชุด deploy ปกติใช้ dependency metadata ของ uv ให้ RapidOCR ใช้ `opencv-python-headless` แทน OpenCV รุ่น GUI เพื่อลดขนาดและไม่พึ่ง Qt/X11 พร้อม lock dependencies ด้วย `uv.lock` ชุดนี้ไม่ติดตั้ง PaddleOCR/PaddlePaddle ที่ต้องมีโมเดลในเครื่อง การติดตั้ง local ด้วย `pip install -r requirements.txt` ยังรวมชุดนี้เหมือนเดิม หรือใช้ `uv sync --extra paddle` แล้วติดตั้งโมเดลตามหัวข้อ OCR ด้านล่าง เมื่อไม่มีโมเดล local ระบบจะใช้เส้นทาง OCR สำรองเดิม; ความสามารถที่ต้องพึ่ง Tesseract/โมเดลใน `.ocr` ยังต้องทดสอบแยกบนโฮสต์นั้น

## การใช้งาน

- **ประสิทธิภาพและการใช้ผลเดิม**: คำขอข้อความเดียวกันที่มีภาษา โทน บริบท คลังคำ และฟีเจอร์ตรงกัน ใช้ผลสำเร็จที่ยังไม่หมดอายุได้ รวมคำขอเหมือนกันที่กำลังทำงานเป็นงานเดียว แปลเอกสารพร้อมกันสูงสุด 3 ส่วนโดยรักษาลำดับและบริบทข้างเคียง OCR ภาพยังใช้ภาพอ่าน 3 แบบเดิมแต่ทำพร้อมกันได้ 2 งาน และแปลชุดป้ายบนภาพได้ 2 ชุดพร้อมกัน PDF สแกนอ่านภาพได้ 2 หน้าพร้อมกันโดยเรนเดอร์ PDF บนเธรดเดิมและเก็บลำดับหน้า ไม่เปลี่ยนโมเดลหรือเอากฎตรวจคำแปลออก
- **แสดงคำแปลหลักก่อน**: เว็บส่ง `defer_additional: true` เพื่อรับคำแปลหลักหรือภาพแปลก่อน แล้วแปลภาษาเพิ่มเติมแยกกัน หากภาษาใดล้มเหลวลองใหม่เฉพาะภาษานั้นได้ การออกจากฟีเจอร์หยุดงานฝั่งหน้าจอและไม่เริ่มงานที่หยุดไว้อัตโนมัติเมื่อกลับเข้า API ที่ไม่ส่งตัวเลือกนี้ยังรับผลภาษาทั้งหมดพร้อมกันตามเดิม ปุ่ม Translate again ขอผลใหม่ด้วย `cache_bypass: true`
- **ขอบเขตแคช**: เก็บเฉพาะหน่วยความจำของแต่ละโปรเซส ไม่เขียนไฟล์ผู้ใช้ลงดิสก์ ข้อความ/คำอ่าน/ผลอ่านไฟล์หมดอายุ 5 นาที ถอดเสียง 2 นาที และเสียงอ่าน 3 นาที จำกัดทั้งจำนวนรายการและขนาดข้อมูล แคชรูปแปล 8 รายการ/32 MiB, ภาพที่ปรับขนาดแล้ว 4 รายการ/16 MiB, พิกัด OCR 8 รายการ/4 MiB และเสียงอ่าน 12 รายการ/16 MiB ลบรายการเก่าตามการใช้งานและตรวจหมดอายุเมื่อรับคำขอ ไม่เก็บข้อผิดพลาดหรือผลหลายภาษาที่มีข้อผิดพลาด API ใช้ `Cache-Control: no-store` สำหรับเบราว์เซอร์ แคชนี้แยกจากประวัติ/รายการโปรดของผู้ใช้
- **เวลาตอบสนอง**: ข้อความแสดงเวลาตั้งแต่ส่งคำขอจนได้รับผล มี `Server-Timing` และ `X-Result-Cache` สำหรับตรวจสอบ ลดการเรียกคำอ่านระหว่างพิมพ์ต่อเนื่อง ใช้ UTF-8 JSON และ gzip สำหรับผล JSON/แค็ตตาล็อกขนาดใหญ่เมื่อเบราว์เซอร์รองรับ เสียงอ่านที่สำเร็จใช้ซ้ำได้และผลถอดเสียงไฟล์เดียวกันใช้ซ้ำได้ บริการ AI ยังมีเวลาเครือข่ายและขีดจำกัดภายนอก เมื่อผิดพลาดจะแสดงผลให้ลองใหม่แทนการซ่อนด้วย SDK retry อัตโนมัติ ผลวัดและข้อจำกัดอยู่ใน `reports/performance-latest.json`
- **สแลงและภาษาถิ่นไทย (Text / Live Chat)**: ใต้ตัวเลือกภาษา เลือก “ตีความภาษาไทย” → สแลง/เหนือ/อีสาน/ใต้ หรือไม่แน่ใจถิ่น ต้นทางต้องเป็น Thai หรือ Detect language รองรับครั้งละ 3,000 ตัวอักษร ผลแสดงความหมายเป็นไทยกลางควบคู่กับคำแปล พร้อมข้อความต้นฉบับที่ใช้อธิบายความหมาย ตัวเลือกถิ่นเป็นคำใบ้จากผู้ใช้ ไม่ใช่ระบบตรวจจับภาษาถิ่นที่ผ่านการรับรอง หากความหมายยังไม่ชัด ระบบไม่สร้างคำแปล ไม่บันทึกประวัติ และไม่ส่งข้อความแชต ให้พิมพ์คำอธิบายหรือยืนยันความหมายที่เป็นไปได้ก่อนแปลใหม่ มีการถามยืนยันเพิ่มเติมสำหรับ “เมื่อย” ในโหมดอีสาน/ไม่แน่ใจ เพื่อแยกเหนื่อยล้าออกจากปวดเมื่อย
- **คลังความหมายส่วนตัว**: เมนู 3 จุด → “คลังสแลงและความหมายภาษาถิ่นของฉัน” บันทึกคำ ความหมายเป็นไทยกลาง ภาษาถิ่น และสถานการณ์ที่ใช้ สูงสุด Text/Live Chat ละ 30 คำ แก้ไขและลบได้ เก็บใน localStorage ของเบราว์เซอร์ แยกจากพจนานุกรมคำแปลเฉพาะและจากฟีเจอร์อื่น เซิร์ฟเวอร์ตรวจรูปแบบและใช้เฉพาะคำที่ปรากฏในข้อความ แต่ไม่เก็บคำเหล่านี้ในฐานข้อมูล ไม่ได้เผยแพร่ให้ชุมชน และไม่ได้ฝึกโมเดลให้จดจำถาวร คำที่ตรงกับข้อความจะถูกส่งให้บริการ AI เป็นบริบท มีตัวอย่างเริ่มต้นเรื่องอาหาร 3 คำ ได้แก่ ลำแต้ๆ / แซ่บหลาย / หรอยจังฮู้ ซึ่งไม่ใช่พจนานุกรมภาษาถิ่นครบถ้วน
- **เสียงพูดในโหมดภาษาถิ่น**: ใช้ระบบถอดเสียงเดิม เมื่อหยุดไมค์จะแสดงข้อความให้ตรวจหรือแก้ก่อน กด Translate/Send จึงเริ่มตีความ ไม่ได้เพิ่มโมเดลเสียงที่ฝึกเฉพาะเหนือ/อีสาน/ใต้ หากถอดเสียงผิดต้องแก้ข้อความก่อน ผลตีความจาก AI ยังอาจผิดได้แม้แสดงสถานะพร้อมแปล ควรให้เจ้าของภาษาถิ่นตรวจในการใช้งานสำคัญ
- **ภาษาที่ใช้จริงในชีวิตประจำวัน**: แปลตามเจตนา สำนวน คำขอทางอ้อม และความสุภาพ โดยไม่ตอบคำถามแทนผู้ใช้ ไม่เติมเหตุผลหรือเดาเพศ มีแนวทางเฉพาะสำหรับไทย อังกฤษ ญี่ปุ่น เกาหลี และจีน ส่วนภาษาอื่นใช้กฎความเป็นธรรมชาติร่วมกัน เลือกเมนู 3 จุด → Context เช่น อาหารและร้านอาหาร ซื้อของ อาการและการพบแพทย์ ท่องเที่ยว หรือทำงาน แต่ละตัวเลือกมีคำแนะนำการใส่บริบท เช่น “คุยกับพนักงานร้านอาหารที่ไม่รู้จักกัน” ระบบเก็บคำปฏิเสธ อาการแพ้ จำนวนเงิน และสิ่งที่ยังไม่ยืนยัน ไม่เพิ่มคำวินิจฉัยในงานแปลอาการ
- **บริบท Live Chat**: ใช้ข้อความสมบูรณ์ 6 ข้อความล่าสุดของคู่ภาษาปัจจุบันช่วยเข้าใจคำอ้างอิงหรือคำตอบสั้น ๆ แต่ละต้นฉบับและคำแปลต้องไม่เกิน 1,500 ตัวอักษรจึงนำมาใช้ ข้อความเหล่านี้ถูกส่งให้บริการ AI พร้อมข้อความปัจจุบัน ไม่ใช้ประวัติ Text/Image/Document การล้างแชตล้างบริบทนี้ด้วย เซิร์ฟเวอร์ไม่จดจำบริบทข้ามคำขอ
- **ตรวจและลองแก้ข้อมูลก่อนส่งผล**: สำหรับข้อความไม่เกิน 5,000 ตัวอักษร หากพบตัวเลข ลิงก์ ตัวแปร หรือศัพท์ที่กำหนดไม่ตรง จะลองแก้เพิ่มเติมได้หนึ่งครั้ง รับผลแก้เฉพาะเมื่อการตรวจทั้งหมดไม่พบจุดต่าง หากบริการแก้ไขขัดข้องหรือยังพบจุดต่าง จะคงคำแปลรอบแรกพร้อมป้ายให้ตรวจ ไม่มีการวนแก้ไม่สิ้นสุด การตรวจนี้ไม่ได้รับรองความหมายทั้งหมด และการเขียนจำนวนเป็นตัวเลขแทนคำอาจทำให้แจ้งเตือนได้ เอกสารยาวใช้ข้อความต้นฉบับใกล้จุดแบ่งช่วยเลือกศัพท์โดยไม่สั่งแปลข้อความข้างเคียงซ้ำ
- **ธงภาษา**: มี SVG ธงประเทศหรือภูมิภาคประกอบครบทั้ง 113 ภาษา เก็บไฟล์ไว้ในโครงการและใช้ร่วมกันทั้งรายการภาษา หัวหน้า และ Live Chat ภาษาอังกฤษใช้สหราชอาณาจักร จีนตัวเต็มใช้ไต้หวัน และกวางตุ้งใช้ฮ่องกง ธงเป็นตัวแทนประกอบภาษา ภาษาหนึ่งอาจใช้ในหลายประเทศ ตรวจจับภาษาอัตโนมัติใช้รูปลูกโลก ชุดธงจาก [flag-icons](https://github.com/lipis/flag-icons) พร้อม MIT license ใน `static/flags/`
- **เลือกภาษา**: มีตัวเลือกแปลข้อความ 113 ภาษา รวมลาว พม่า เขมร อาหรับ ฮินดี และจีนตัวย่อ/ตัวเต็ม คุณภาพขึ้นกับโมเดลและภาษา ไม่ใช่การรับรองว่ารองรับทุกภาษาในโลก กดภาษาต้นทางหรือปลายทางเพื่อเปิดหน้าต่างค้นหา รองรับชื่อไทย อังกฤษ และชื่อภาษาท้องถิ่น แสดงธง ชื่อภาษา และเครื่องหมายภาษาปัจจุบัน ใช้ปุ่มลูกศรและ Enter เพื่อเลือก หรือ Escape เพื่อปิดได้ โหมด Live Chat เลือกภาษาสองฝั่งโดยไม่ใช้ Detect language
- **แยกการทำงานแต่ละโหมด**: Text, Image, Document และ Live Chat เก็บข้อความ ภาษา น้ำเสียง ผลแปล ไฟล์ และสถานะของตัวเอง สลับแล้วกลับมาทำต่อได้โดยไม่ย้ายข้อมูลข้ามโหมด การออกจากโหมดจะหยุดไมค์ กล้อง เสียงอ่าน ตัวหน่วงแปล และคำขอที่ค้าง ผลตอบกลับเก่าถูกตรวจเจ้าของก่อนใช้ การสลับหน้าไม่ส่งคำขอ AI ใหม่โดยอัตโนมัติ งานอ่านเอกสารที่ยังไม่เสร็จมีปุ่ม Retry ส่วนรูปที่ยกเลิกกดลองใหม่ได้ ข้อมูลชั่วคราวอยู่จนรีโหลด ธีมและภาษาเมนูเป็นค่าของทั้งแอป
- **Text**: พิมพ์หรือวางข้อความ ระบบแปลอัตโนมัติหลังหยุดพิมพ์ 0.45 วินาที และแปลใหม่เมื่อเปลี่ยนภาษา สลับภาษา หรือปรับน้ำเสียง กด Translate หรือ Ctrl / ⌘ + Enter เพื่อแปลทันทีได้ รองรับ 5,000 ตัวอักษร สลับภาษา คัดลอก ดาวน์โหลดคำแปล และอ่านออกเสียงได้
- **คำอ่านและตัวอย่าง**: หลังแปลข้อความสั้นไม่เกิน 1,500 ตัวอักษร ระบบแสดงคำอ่านอักษรละตินสำหรับภาษาที่ไม่ได้ใช้อักษรละติน พร้อมตัวอย่างการพูดอีก 2 แบบ กดตัวอย่างเพื่อเปลี่ยนต้นฉบับและแปลอัตโนมัติ แสดงจำนวนคำด้วย `Intl.Segmenter` และจำนวนตัวอักษร
- **Translation Studio**: หลังแปล Text หรือ Document กด Deep review เพื่อแปลกลับโดยไม่ให้ขั้นตอนแปลกลับเห็นต้นฉบับ แล้วตรวจความหมาย ความกำกวม น้ำเสียง และการใช้คำเฉพาะ ผลมีข้อความอ้างอิงจากต้นฉบับและคำแปลทางเลือกพร้อมเหตุผล เลือกใช้แล้วตรวจรูปแบบซ้ำได้โดยไม่เรียก AI และย้อนกลับคำแปลเดิมได้ รองรับครั้งละต้นฉบับ 3,000 ตัวอักษรและคำแปล 9,000 ตัวอักษร ไม่มีการให้เปอร์เซ็นต์ความแม่นยำที่ไม่ได้สอบเทียบ
- **ตรวจตัวเลข/ลิงก์/ตัวแปร/คำเฉพาะ**: ทุกคำแปลตรวจการหายไปหรือเพิ่มมาของข้อมูลเหล่านี้โดยไม่เรียก AI เพิ่ม แสดงเป็นจุดให้ทบทวน ไม่ใช่การตัดสินความถูกต้องทางความหมาย การเขียนตัวเลขเป็นคำหรือเปลี่ยนรูปแบบวันที่อาจทำให้แจ้งเตือนได้ Text/Document แสดงป้ายตรวจรูปแบบ ส่วน Image และ Live Chat แสดงรายละเอียดเมื่อมีจุดที่ควรตรวจ
- **เปรียบเทียบคำแปล A/B**: วางคำแปลอีกแบบใน Studio ผู้ตรวจจะเห็นคำแปลสุ่มลำดับ A/B โดยไม่มีชื่อระบบ ให้ความเห็นด้านความหมาย ความเป็นธรรมชาติ น้ำเสียง และศัพท์ พร้อมแสดงคู่เทียบ A/B ให้ผู้ใช้หลังตรวจและดาวน์โหลดรายงาน JSON ได้ นี่เป็นความเห็นจาก AI ไม่ใช่หลักฐานรับรองว่าเหนือกว่า Google Translate หรือผล benchmark อิสระ
- **พจนานุกรมคำเฉพาะ**: เมนู 3 จุด → My terminology เพิ่มคำต้นฉบับ คำแปลที่ต้องการ และภาษาปลายทาง สูงสุดฟีเจอร์ละ 30 คำ บันทึกแยก Text/Image/Document/Live Chat ในเบราว์เซอร์ ระบบใช้เฉพาะคำที่ปรากฏในต้นฉบับและตรงกับภาษาปลายทาง พร้อมแจ้งเตือนหากผลแปลไม่พบคำที่กำหนด การแปลเพิ่มเติมและการแปลตอบกลับใช้ศัพท์ตามภาษาปลายทางของคำขอนั้นเช่นกัน
- **Why this? / Check translation**: กดเพื่อใหั AI อธิบายการเลือกคำ หรือตรวจความหมาย/ความเป็นธรรมชาติ หากมีคำแปลที่เสนอให้แก้ไข จะมีปุ่มให้เลือกนำมาใช้ การตรวจทานเป็นความเห็นจาก AI
- **Reply**: พิมพ์คำตอบเป็นภาษาปลายทาง แล้วแปลกลับเป็นภาษาต้นทาง กด Suggest 3 replies เพื่อรับคำตอบที่เหมาะกับข้อความจริง เลือกคำตอบมาแก้ไขก่อนแปลได้ พร้อมคัดลอกและฟังคำตอบที่แปลแล้ว
- **ประวัติและรายการโปรด**: เมนู `⋮` → History & favorites บันทึกคำแปลสำเร็จอัตโนมัติในเบราว์เซอร์ แยกทั้ง 4 โหมด ค้นหาต้นฉบับ/คำแปล กรองรายการโปรด กดดาว คัดลอก ลบรายรายการ และล้างประวัติเฉพาะโหมดได้ เก็บสูงสุดโหมดละ 100 รายการ โดยเก็บรายการโปรดไว้ก่อนรายการทั่วไป คำแปลที่เคยบันทึกจากรุ่นเดิมยังอ่านเป็นรายการโปรดได้ ไม่มีการซิงก์ข้ามอุปกรณ์ ประวัติรูปเก็บข้อความที่อ่านได้และคำแปล ไม่เก็บไฟล์ภาพลง localStorage
- **Image**: เลือกรูปหรือลาก PNG, JPEG, WebP, HEIC/HEIF หรือเปิดกล้องถ่ายรูป ระบบอ่านพิกัดข้อความด้วย Tesseract แล้วส่งแต่ละข้อความไปแปลผ่าน Groq และวางคำแปลกลับลงบนตำแหน่งเดิม รูปอาหารและส่วนอื่นของภาพยังคงเป็นรูปเดิม สลับดูต้นฉบับ เปิดเต็มจอ ซูม แตะคำแปลเพื่ออ่าน/คัดลอก/ฟัง และดาวน์โหลดภาพ PNG ที่มีคำแปลได้ เปลี่ยนภาษาแล้วระบบแปลรูปใหม่อัตโนมัติ รองรับ 10 MB, 25 ล้านพิกเซล และข้อความไม่เกิน 160 ส่วน รูปปรับขนาดสูงสุด 2,200 พิกเซล ภาพตัวอักษรเล็ก เบลอ หรือแต่งฟอนต์มากอาจอ่านคลาดเคลื่อน ควรเทียบต้นฉบับเมื่อไม่แน่ใจ
- **Document**: เลือก TXT, Markdown, CSV (UTF-8), PDF หรือ DOCX ขนาดไม่เกิน 10 MB และข้อความไม่เกิน 30,000 ตัวอักษร PDF รองรับสูงสุด 20 หน้า รวมถึงหน้าสแกนที่ต้องอ่านด้วย AI ข้อความและตาราง DOCX จะอ่านตามลำดับเอกสาร คำแปลดาวน์โหลดเป็น TXT แบบ UTF-8 การจัดหน้า/รูปแบบเดิมไม่ได้ส่งออกตามไปด้วย
- **Live Chat**: สนทนาสองภาษา เลือกภาษาที่กำลังพิมพ์หรือกดไมค์ของผู้พูด แต่ละข้อความแสดงต้นฉบับและคำแปลพร้อมฟัง/ขยายได้ ใช้ต้นฉบับ 6 ข้อความล่าสุดช่วยแก้คำอ้างอิงและประโยคตอบสั้น โดยไม่เติมส่วนท้ายของประโยคที่ยังไม่จบ ค่าเริ่มต้นเมื่อกดหยุดไมค์จะถอดเสียง แปล และส่งข้อความอัตโนมัติ เปิด “ตรวจข้อความจากไมค์ก่อนส่ง” ได้หากต้องการตรวจหรือแก้ก่อนส่ง ข้อความที่ข้อมูลเสียงบ่งชี้ว่าไม่ชัดจะยังต้องตรวจ ข้อความพิมพ์กด Enter เพื่อส่ง และ Shift+Enter เพื่อขึ้นบรรทัดใหม่ เก็บบทสนทนาแยกจากโหมดอื่นจนกดล้างหรือรีโหลด
- **แอนิเมชันไมค์**: ระหว่างบันทึก ปุ่มไมค์เปลี่ยนเป็นคลื่น 5 แถบตามระดับเสียงด้วย Web Audio พร้อมตัวจับเวลาที่ปุ่มหลัก ระหว่างเปิดไมค์/ถอดเสียงแสดงวงหมุน ใช้ได้กับไมค์แต่ละฝั่งใน Live Chat และหยุดเมื่อยกเลิก เปลี่ยนโหมด หรือเกิดข้อผิดพลาด รองรับการตั้งค่าลดการเคลื่อนไหว หากวิเคราะห์ระดับเสียงไม่ได้จะใช้แอนิเมชันสำรอง
- **ไมโครโฟน**: มีภาษาหรือรูปแบบภาษาให้เลือกถอดเสียง 101 รายการ จีนตัวเต็มส่งรหัสจีนให้ Whisper และ Javanese ใช้รหัส jw ภาษาที่ไม่มีไมค์ยังพิมพ์แปลหรือสนทนาได้ ใช้ MediaRecorder และส่งเสียงให้ Groq Whisper จึงไม่ต้องพึ่งระบบรู้จำเสียงเฉพาะของ Chrome บันทึกครั้งละไม่เกิน 60 วินาที ต้องอนุญาตไมโครโฟนและเปิดผ่าน localhost หรือ HTTPS ใช้ Whisper Large V3 รุ่นเต็มเป็นค่าเริ่มต้น ขอเสียง mono พร้อมลดเสียงรบกวน/สะท้อนตามที่เบราว์เซอร์รองรับ บันทึก 128 kbps และตรวจเสียงเงียบก่อนส่ง การตั้งค่านี้ไม่รับประกันว่าจะอ่านทุกสำเนียงหรือชื่อเฉพาะได้ถูก ดูตัวอย่างทดสอบจริงใน `reports/voice-quality-synthetic.json`
- **ตรวจเทียบเสียงใน Live Chat**: ใช้ Whisper รุ่นหลักและอีกรุ่นตรวจพร้อมกัน เพิ่มคำขอถอดเสียง 1 ครั้งต่อการบันทึก เมื่อได้ข้อความต่างกันจะเก็บผลหลักไว้ให้ตรวจแก้ก่อนส่ง ไม่ให้ AI เดาคำแทน ถ้าตัวตรวจล้มเหลวจะยังแสดงข้อความหลักให้ตรวจ และไม่แคชความล้มเหลวนั้น ใช้คำศัพท์เฉพาะที่บันทึกในโหมดและทิศทางผู้พูดปัจจุบันช่วยสะกด โดยไม่ส่งประวัติของโหมดอื่น การเห็นตรงกันไม่รับประกันว่าถูกต้อง โดยเฉพาะชื่อเฉพาะและสำเนียง ทดสอบจำลองล่าสุดอยู่ใน `reports/voice-upgrade-2026-10-26.json` ตั้ง `GROQ_SPEECH_VERIFY_MODEL=` เพื่อปิดการตรวจเพิ่มได้
- **อ่านออกเสียง**: รอรายการเสียงในเบราว์เซอร์สั้น ๆ เพื่อรองรับการเปิดครั้งแรก ถ้าเสียงในเครื่องล้มเหลวจะลองเซิร์ฟเวอร์ เมื่อเซิร์ฟเวอร์ไม่ส่งเสียงหรือเกิดปัญหาเครือข่ายจะลองใหม่อีกครั้งภายในเวลาไม่เกิน 35 วินาที พร้อมเสียงสำรองสำหรับภาษาหลัก โดยทิ้งเสียงบางส่วนที่ล้มเหลว ไม่ต่อเสียงซ้ำ ใช้เสียงภาษานั้นที่ติดตั้งในเบราว์เซอร์ หากไม่มีจะรับเสียงจาก Microsoft Edge ผ่านเซิร์ฟเวอร์ กดปุ่มลำโพงซ้ำเพื่อหยุด มีเสียงอ่านบนเซิร์ฟเวอร์ 75 ภาษา และใช้เสียงที่ติดตั้งในเบราว์เซอร์ได้ ตรวจจับภาษาสำหรับต้นทางแบบ Auto หากไม่มีเสียงภาษานั้นจะแจ้งให้ทราบ
- **เมนู `⋮`**: แยกเป็นแท็บการแปล ประวัติ/รายการโปรด และการแสดงผล ปุ่มแท็บอยู่ด้านบนตลอด ใช้ปุ่มลูกศร/Home/End เปลี่ยนแท็บได้ แท็บการแสดงผลรวมภาษาแอปและปุ่มเปลี่ยนธีม แท็บการแปลเลือก Tone/Context จากการ์ดพร้อมไอคอนและเครื่องหมายรายการที่เลือก มีคำอธิบายบริบทและใช้ปุ่มลูกศร/Enter/Escape ได้ การเลือกยังใช้ค่าจริงแยกตามฟีเจอร์ โดย Tone มี Natural / Friendly / Formal / Casual และ Context มี General / Travel / Work / Study / Conversation / Food & restaurants / Shopping / Symptoms & healthcare และบริบทเพิ่มเติมสูงสุด 1,000 ตัวอักษร ค่าจะแนบไปใช้แปลและให้ผู้ช่วยพิจารณาจริง ตั้งค่าแยกตามโหมด Live Chat เปิดเมนูจากปุ่ม 3 จุดบนหัวหน้าได้เช่นกัน
- **แปลหลายภาษา**: เปิด Translate into several languages แล้วเลือกเพิ่มได้สูงสุด 3 ภาษา ค้นหาจากรายการ 113 ภาษา คำแปลหลักยังแสดงได้แม้ภาษาเพิ่มเติมบางภาษาล้มเหลว และกดลองใหม่เฉพาะภาษาที่ผิดพลาดได้ ใน Text/Document แสดงเป็นการ์ดเพิ่มเติม ใน Image แสดงคำแปลเพิ่มเติมเป็นข้อความใต้รูป (คำแปลหลักยังวางบนภาพ) ใน Live Chat แสดงใต้ข้อความของแต่ละการ์ด คัดลอก/อ่านออกเสียงการ์ดเพิ่มเติมของ Text/Document/Image ได้ และผลสำเร็จแต่ละภาษาจะเข้าประวัติของโหมดนั้น
- **ภาษาเมนู**: เริ่มต้นเป็นอังกฤษ เปลี่ยนได้ใน `⋮ → Appearance → App language` และจำภาษาบนอุปกรณ์ ใช้คำแปลที่มีในแอปเท่านั้น ไม่เรียก AI และไม่ใช้โควตา API มีคำแปลเมนูครบตามแค็ตตาล็อก 113 ภาษา โหลดรายการจาก `static/interface-locales.js` และคำแปลจาก `static/interface-locales/` รายการนี้แยกจากภาษาที่ใช้แปลเนื้อหา ดู [วิธีเตรียมไฟล์และข้อจำกัดด้านคุณภาพ](static/interface-locales/README.md)
- ปุ่มธีมแสดงดวงอาทิตย์เมื่อสว่างและพระจันทร์เมื่อมืด มีแอนิเมชันหมุน/ย่อขยายไอคอนและเปลี่ยนสีอย่างนุ่มนวล จำธีมบนอุปกรณ์และรองรับการตั้งค่าลดการเคลื่อนไหว

ไฟล์ประมวลผลในหน่วยความจำและไม่บันทึกลงโฟลเดอร์โครงการ ข้อความแปล รูปภาพ/PDF สแกน และเสียงบันทึกจะส่งไปยัง Groq ตามฟังก์ชันที่ใช้ การอ่านออกเสียงบนเซิร์ฟเวอร์ส่งข้อความไปยัง Microsoft Edge TTS บริการเหล่านี้ต้องเชื่อมต่ออินเทอร์เน็ตและอาจจำกัดโควตาการใช้งาน

สำหรับเอกสาร PDF สแกน หากหน้าใดมีข้อความหนาแน่นจนเกินขีดจำกัดผลลัพธ์ ระบบจะแจ้งให้แบ่งภาพ ไม่ส่งคำแปลที่ถูกตัดให้โดยไม่แจ้ง ขยาย `GROQ_VISION_MAX_TOKENS` ได้เมื่อโควตาบัญชีรองรับ

## ติดตั้ง OCR สำหรับแปลบนรูป

เส้นทางหลักสำหรับไทย–อังกฤษใช้ตัวตรวจจับ **PP-OCRv6 medium** ร่วมกับตัวอ่าน **th_PP-OCRv5_mobile_rec** ส่วนอังกฤษ จีน ญี่ปุ่น และกลุ่มภาษา Latin ที่รองรับ ใช้ตัวอ่าน **PP-OCRv6 medium** ทั้งหมดประมวลผลด้วย CPU ในเซิร์ฟเวอร์ รุ่น v6 ไม่ใช่ตัวอ่านไทย จึงแยกโมเดลตามภาษา อ้างอิง [โมเดลไทยทางการ](https://huggingface.co/PaddlePaddle/th_PP-OCRv5_mobile_rec) และ [รายการโมเดล PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/module_usage/text_recognition.en.md)

```bash
source .venv/bin/activate
pip install -r requirements.txt
python scripts/setup_paddle_ocr.py
python app.py
```

แพ็กเกจ CPU ที่ทดสอบร่วมกันอยู่ใน `requirements-paddle.txt` สคริปต์ดาวน์โหลดโมเดลทางการไว้ใน `.ocr/paddle/` และบันทึก URL/SHA256 ของไฟล์ที่ดาวน์โหลด รันซ้ำข้ามโมเดลที่มีครบแล้ว ไม่มีการดาวน์โหลดโมเดลระหว่างแปลรูป ตรวจสถานะได้ที่ `/api/ocr-status` คำขอแรกต้องโหลดโมเดลเข้า RAM ก่อน คำขอต่อไปใช้โมเดลเดิมและมีแคชคำอ่าน การประมวลผล Paddle ต่อโปรเซสทำทีละรูปเพื่อไม่ให้ predictor แข่งกันและจำกัดภาระ CPU

คำอ่าน Paddle ที่ความมั่นใจอย่างน้อย 80% ไม่ส่งให้ vision เขียนทับ แต่คะแนนนี้ไม่รับประกันว่าทุกคำถูกต้อง คำอ่านที่ไม่มั่นใจยังมีเส้นทางตรวจภาพตัด ภาษาหรือชุดภาษาผสมที่ตัวอ่าน Paddle ไม่รองรับ และเครื่องที่ยังไม่ติดตั้งโมเดล ใช้เส้นทาง Tesseract/RapidOCR เดิม ถ้าโมเดล Paddle ที่ติดตั้งแล้วทำงานผิดพลาดจะแสดงข้อผิดพลาดโดยตรง ไม่ซ่อนเป็นผล OCR สำเร็จ

ทดสอบโมเดลจริงซ้ำด้วย `python scripts/benchmark_paddle_ocr.py` (ไม่ใช้โควตา API) สคริปต์สร้างเมนูไทยตัวเล็กพร้อมราคาและรายงานคำที่ตรงต้นฉบับแบบดิบ ผลตัวอย่างอยู่ใน `reports/paddle-ocr-synthetic.json` เป็นภาพสร้างสำหรับตรวจ regression ไม่ใช่ benchmark เทียบ Google Lens หรือผลจากรูปต้นฉบับของผู้ใช้

OCR บนรูปรองรับภาษาต้นทาง 99 ตัวเลือกจากรายการภาษา (113 ตัวเลือกสำหรับข้อความ) รวมลาว เขมร พม่า อาหรับ และจีนตัวเต็ม ภาษาอื่นยังใช้โหมดข้อความได้ ความแม่นยำขึ้นกับภาษาและคุณภาพรูป บน Ubuntu/Debian เครื่องใหม่ให้รัน:

```bash
python scripts/setup_ocr.py
```

สคริปต์แตก Tesseract จาก apt ไว้ใน `.ocr/` โดยไม่ใช้ sudo แล้วดาวน์โหลดโมเดลที่ตรงกับ catalog จาก revision ที่ระบุของ [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) และใช้ Thai `tessdata_best` เหมือนเดิม ดาวน์โหลดพร้อมกันไม่เกิน 4 ไฟล์และเปลี่ยนไฟล์เมื่อดาวน์โหลดสมบูรณ์เท่านั้น รันซ้ำจะข้ามโมเดลที่มีแล้ว โฟลเดอร์นี้ไม่ถูกนำเข้า version control

```bash
# มี runtime แล้ว: เพิ่มชุดภาษาที่ขาดทั้งหมด
python scripts/setup_ocr.py --models-only
# ติดตั้งเฉพาะไทย อังกฤษ อาหรับ
python scripts/setup_ocr.py --languages th,en,ar
```

Windows/macOS ให้ติดตั้ง Tesseract ผ่าน package manager ของระบบก่อน แล้วใช้ `--models-only` พร้อมตั้ง `TESSDATA_PREFIX` เป็นพาธเต็มของ `.ocr/usr/share/tesseract-ocr/5/tessdata` เพิ่ม `tesseract` ใน PATH หรือกำหนด `TESSERACT_CMD` หากภาษาที่เลือกยังไม่มีโมเดลบนเครื่อง ระบบจะแจ้งข้อผิดพลาดแทนการใช้ภาษาอื่นแทน

HEIC/HEIF ใช้ [pillow-heif](https://pillow-heif.readthedocs.io/en/latest/pillow-plugin.html) เปิดภาพหลักและปรับ orientation บนเซิร์ฟเวอร์ ภาพตัวอย่างและไฟล์ดาวน์โหลดเป็น PNG จึงดูได้แม้เบราว์เซอร์ไม่รองรับ HEIC โดยตรง จำกัด 10 MB และ 25 ล้านพิกเซลเหมือนรูปชนิดอื่น

การคงราคา/ตัวเลขไม่อาศัยข้อความที่ OCR อ่านมา: ระบบแยกบริเวณตัวเลขและขยายกรอบด้วยตัวตรวจจับข้อความ แล้ววางพิกเซลจากภาพต้นฉบับคืนบนบริเวณนั้นหลังวางคำแปล ทั้งบนหน้าเว็บและใน PNG ที่ดาวน์โหลด จึงไม่วาดราคาใหม่จากค่าที่ AI/OCR เดา เวลา เบอร์โทร และข้อความที่ประกอบด้วยตัวเลขคงตามภาพ ส่วนรายการคำแปลไม่แสดงค่าตัวเลขที่ยังไม่ได้ยืนยัน

ในเส้นทางสำรอง ใช้ตัวตรวจจับตำแหน่งข้อความจากโมเดล PP-OCRv4 ของ [RapidOCR](https://rapidai.github.io/RapidOCRDocs/v1.4.4/install_usage/api/RapidOCR/) แยกจากการอ่านคำของ Tesseract เพื่อเก็บหัวข้อที่อ่านไม่ออกโดยไม่เดาพิกัด ใช้โมเดลที่มากับแพ็กเกจในเครื่อง ไม่มีการดาวน์โหลดโมเดลระหว่างรับคำขอ กรอบที่ยังอ่านไม่ออกจะส่งตรวจภาพและแสดงให้ตรวจหากยังไม่ชัด

การอ่านรูปตัวหนังสือเล็กในเส้นทางสำรองใช้ภาพซ้อนทับ 4 ส่วนที่ขยายก่อน OCR และเก็บข้อความสีขาวบนพื้นดำจากการอ่านรอบปกติด้วย จากนั้นรวมภาพตัดของข้อความเล็ก/ไม่มั่นใจไม่เกิน 30 ส่วนเป็นภาพเดียว ส่งให้ Groq Vision ตรวจคำอ่านในภาษาต้นฉบับ โดยไม่ให้ AI เดาพิกัดใหม่ ชุดคำอ่านใช้ซ้ำได้เมื่อเปลี่ยนภาษาปลายทาง ถ้า AI อ่านไม่ชัดจะเก็บรูปเดิมและทำเครื่องหมายให้ตรวจ แทนการเดาเมนู ข้อผิดพลาด/โควตาของผู้ให้บริการแสดงแยกจากข้อความอ่านไม่ชัด ผลที่ยังมีส่วนอ่านไม่ชัดไม่บันทึกเข้าประวัติหรือแปลต่อเป็นภาษาเพิ่มเติมอัตโนมัติ

เหนือรูปมีปุ่มบอกภาษาปลายทางและเปลี่ยนภาษาได้ พร้อมจำนวนส่วนที่แปลได้ ใต้รูปเปิด “อ่านคำแปลทั้งหมด” เพื่ออ่านขนาดตัวอักษรปกติและแตะคัดลอก/ฟังแต่ละคำแปลได้ ผลภาษาอังกฤษที่ยังเหลืออักษรไทยจะลองซ่อมหนึ่งครั้งก่อนแจ้งข้อผิดพลาด และมีการตรวจความต่างระหว่างข้าวกะเพรากับข้าวผัด ข้อความเล็ก เบลอ หรือฟอนต์ตกแต่งยังอาจอ่านคลาดเคลื่อน ควรเทียบต้นฉบับ

เฉพาะภาพตัดที่ต้องตรวจคำอ่านเพิ่มเติมจะส่งไป Groq Vision แม้เลือกภาษาต้นทางเอง ส่วนการหาตำแหน่งข้อความยังประมวลผลในเซิร์ฟเวอร์ ไม่บันทึกรูปลงดิสก์

Detect language ตรวจหลายภาษาในรูปเดียว รวมข้อความรายการเล็กใต้หัวข้ออังกฤษ และตรวจไทย/อังกฤษร่วมกันเมื่อโมเดลเห็นแต่อังกฤษ เพื่อไม่ข้ามรายการไทยเพราะคำว่า Menu ตรงหัวภาพ ป้ายที่เป็นภาษาปลายทางอยู่แล้วจะเก็บไว้เหมือนเดิม หากไม่มีข้อความเปลี่ยน ระบบจะแจ้งเหนือรูปแทนข้อความว่าแปลสำเร็จ ภาพที่เบลอหรือมีตัวอักษรเล็กมากยังอาจอ่านไม่ครบ ควรเทียบกับรูปต้นฉบับ

OCR ของรูปทำในเครื่องเซิร์ฟเวอร์ ข้อความที่อ่านได้ส่งไปยัง Groq เพื่อแปล หากใช้ Detect language รูปจะส่งไปยังโมเดล vision เพื่อช่วยเลือกชุดภาษา OCR การอ่านตำแหน่งข้อความไม่ต้องให้ AI เดาพิกัดเอง รองรับกล้องผ่าน HTTPS หรือ localhost และต้องอนุญาตสิทธิ์กล้องก่อน

ระหว่างแปลรูปจะแสดงเวลาที่ผ่านไปและปุ่มยกเลิก หากรอเกิน 90 วินาทีจะแจ้งให้ลองใหม่โดยเก็บรูปไว้ เมื่อ Groq ตอบ 429 จะแสดงเวลารอก่อนลองใหม่บนรูป ระบบเก็บผลสำเร็จล่าสุด 8 รายการในหน่วยความจำและรวมคำขอรูป/ภาษา/โทนเดียวกันที่กำลังทำงาน เพื่อลดการเรียก AI ซ้ำ ข้อผิดพลาดไม่ถูกเก็บเป็นผลแปล

## การตั้งค่า `.env`

| ตัวแปร | ค่าเริ่มต้น / ความหมาย |
| --- | --- |
| `GROQ_API_KEY` | จำเป็น: API key ของ Groq |
| `GROQ_MODEL` | `openai/gpt-oss-120b` สำหรับแปลข้อความ |
| `GROQ_TRANSLATION_REASONING_EFFORT` | `medium` สำหรับ gpt-oss เพื่อให้คิดความหมายก่อนเรียบเรียง ใช้ `low` เพื่อลดเวลา/โทเคน หรือตั้งค่าว่างเพื่อใช้ค่าเริ่มต้นของผู้ให้บริการ |
| `GROQ_BASE_URL` | `https://api.groq.com/openai/v1` |
| `GROQ_VISION_MODEL` | `qwen/qwen3.8-27b` สำหรับอ่านข้อความในภาพ |
| `GROQ_VISION_MAX_TOKENS` | `900` จำกัดผลลัพธ์ต่อภาพให้เหมาะกับโควตาปัจจุบัน |
| `GROQ_SPEECH_MODEL` | `whisper-large-v3` รุ่นเต็มสำหรับถอดเสียง เน้นความแม่นยำหลายภาษา มีต้นทุนต่อเสียงสูงกว่า Turbo |
| `GROQ_SPEECH_VERIFY_MODEL` | `whisper-large-v3-turbo` ใช้ตรวจเทียบเสียงใน Live Chat แบบขนาน เพิ่มคำขอถอดเสียง 1 ครั้ง ตั้งค่าว่างเพื่อปิด |
| `GROQ_CHAT_REASONING_EFFORT` | `medium` สำหรับ Live Chat เมื่อใช้ gpt-oss เพื่อทบทวนความหมายมากขึ้น อาจใช้เวลานานกว่าโหมดข้อความที่ตั้ง `low` |
| `PADDLE_OCR_ENABLED` | `1` เปิด Paddle เมื่อมีโมเดลครบ ตั้ง `0` เพื่อใช้เส้นทางเดิม |
| `PADDLE_OCR_THREADS` | `2` เธรด CPU สำหรับ Paddle จำกัด 1–8 |
| `TESSERACT_CMD` | ไม่จำเป็นถ้ามี `tesseract` ใน PATH หรือใช้ `.ocr/` จากสคริปต์ |
| `TESSDATA_PREFIX` | กำหนดเมื่อใช้ชุดภาษา OCR ในพาธอื่น |
| `PORT` | `5000` |
| `FLASK_DEBUG` | `0` ตั้ง `1` เมื่อต้องการ debugger ระหว่างพัฒนา |

## ตรวจสอบ

ดู[ผลเทียบ Google Translate หลังปรับ เป็นประโยคเต็ม 26 ข้อ](reports/google-comparison-v2/README.md) แยกข้อที่ใช้พัฒนาระบบกับประโยคใหม่ พร้อมผลดิบและภาพ Google ไม่ใช่คะแนนความแม่นยำของทุกภาษา

การเรียบเรียงเริ่มจากความหมายและชนิดประโยค แล้วใช้ไวยากรณ์ภาษาปลายทางที่เป็นธรรมชาติ ประโยคสมบูรณ์ต้องได้ประโยคที่อ่านลื่น ส่วนวลีที่ยังไม่จบจะไม่เติมเหตุการณ์ใหม่ให้ ระบบแนบหมายเหตุภาษาเฉพาะเมื่อพบคำที่เกี่ยวข้อง (`linguistic_guidance.py`) เช่น สำนวนในบริบทงานเทียบกับผักจริง คำถามเหนือ/อีสานที่มีหลักฐานร่วม และความถี่แบบ alternate days/week หมายเหตุเป็นความหมายที่เป็นไปได้ ไม่ใช่คำตอบทั้งประโยคหรือการแทนคำอัตโนมัติ คำอย่าง กา หรือ จ้อง เดี่ยว ๆ ไม่พอให้เปลี่ยนเป็นภาษาเหนือ การตรวจทานอีกรอบจะเห็นหมายเหตุเดียวกันและตรวจสำนวน ความถี่ และความลื่นไหลที่มีผลต่อความหมายด้วย

การตรวจความหมายเพิ่มเติมเปิดเป็นค่าเริ่มต้นสำหรับ Live Chat ข้อความที่มีคำปฏิเสธ/เงื่อนไขไทยหรืออังกฤษ โหมดร้านอาหาร/สุขภาพ และข้อความที่มีคลังคำหรือบริบทสนทนา รองรับต้นฉบับไม่เกิน 3,000 ตัวอักษรต่อคำขอ โดยเทียบคำแปลกับต้นฉบับโดยตรงอีกหนึ่งครั้ง แก้เฉพาะปัญหาความหมายที่อ้างข้อความจริงได้ และไม่ยอมรับคำแก้ที่ทำให้การตรวจตัวเลข ลิงก์ ตัวแปร หรือคำเฉพาะผิดเพิ่ม ไม่ตรวจเอกสารยาวทั้งฉบับด้วยขั้นตอนนี้

API ส่งสถานะ `quality_review` แยกจาก `audit` ซึ่งตรวจรูปแบบข้อมูล หากยังต้องถามความหมาย หน้าเว็บเก็บข้อความไว้และไม่ส่งเข้าบทสนทนา หากการตรวจเพิ่มเติมใช้ไม่ได้ จะแสดงคำแปลเดิมพร้อมข้อความแจ้ง และไม่เก็บผลนั้นเป็นแคชสำเร็จ การตรวจเป็นความเห็นของโมเดล ไม่ใช่คะแนนความแม่นยำหรือการรับรองความถูกต้อง เพิ่มคำขอ API สูงสุดหนึ่งครั้ง มี timeout 20 วินาที ตั้ง `SEMANTIC_REVIEW_ENABLED=0` เพื่อปิดได้

ทดสอบบริการจริงด้วย `python scripts/benchmark_semantic_review.py --live` (ใช้โควตา API) ผลตัวอย่างอยู่ใน `reports/semantic-review-seeded.json` เป็นโจทย์ที่จงใจใส่คำแปลผิด ไม่ใช่คะแนนความแม่นยำของทั้งระบบ

```bash
pip install -r requirements-dev.txt
npm ci
python -m unittest discover -s tests -v
ruff check .
ruff format --check .
npm run check
npm run format:check
```

ชุดทดสอบไม่เรียกบริการเสียเงิน ตรวจสอบไฟล์จริง TXT/DOCX/PDF และจำลองเฉพาะคำตอบ AI/เสียง เพื่อทดสอบการตรวจข้อมูล การแบ่งเอกสารยาว PDF สแกน ขีดจำกัดไฟล์ และการตอบข้อผิดพลาด

จัดรูปแบบ Python ด้วย `ruff format .` และ frontend ด้วย `npm run format` เครื่องมือ Node เป็น development dependencies เท่านั้น การรันเว็บยังใช้ `python app.py` ตามเดิม ต้องการทดสอบเบราว์เซอร์ให้รัน `npx playwright install chromium` แล้วเปิด Flask อีก terminal ก่อนสั่ง `npm run test:browser` ดูข้อกำหนดไลบรารีระบบใน `tests/browser/README.md`

การอ่าน TXT/Markdown/CSV/DOCX และ PDF ที่มีข้อความในตัวไม่เรียก AI หรือขอ API key ส่วนภาพและ PDF สแกนจะสร้าง AI client เฉพาะตอนต้องอ่านภาพ การแปลข้อความยังต้องใช้ API key ตามเดิม

### ตรวจคำแปลด้วยโมเดลอีกค่ายแบบเลือกเคส

ตัวแปลหลักยังเป็น GPT-OSS 120B บน Groq ระบบ `model_routing.py` เลือก Gemini
เฉพาะการตรวจความหมายข้อความไม่เกิน 3,000 ตัวอักษรที่มีสัญญาณเสี่ยง เช่น คำปฏิเสธ
เงื่อนไข สำนวน บริบทสุขภาพ หรือคำศัพท์เฉพาะ บทสนทนาทั่วไปเพียงอย่างเดียวไม่เปิด Gemini
ไม่เปลี่ยนโมเดล OCR เสียง หรือการตีความภาษาถิ่นเฉพาะโหมด และไม่รับประกันความแม่นยำเพิ่มขึ้น

เปิดใช้งานใน `.env` บนเครื่องของคุณ แล้วเริ่มเซิร์ฟเวอร์ใหม่:

```dotenv
TRANSLATION_REVIEW_PROVIDER=gemini
GEMINI_API_KEY=ใส่คีย์ของคุณในเครื่องเท่านั้น
GEMINI_REVIEW_MODEL=gemini-3.5-flash-lite
```

หากไม่มีคีย์ ระบบใช้ Groq ตามเดิม หาก Gemini ขัดข้อง ระบบเก็บคำแปลฉบับเดิม
และรายงานการตรวจว่า `unavailable` โดยไม่เรียกโมเดลสำรองซ้ำเพิ่มค่าใช้จ่าย
ผลที่ตรวจไม่ได้จะไม่ถูกเก็บในแคชสำเร็จ ปิดด้วย `TRANSLATION_REVIEW_PROVIDER=groq`
ตรวจเส้นทางได้จาก `quality_review.provider` และ `quality_review.model` ในผล API
การตรวจยังต้องผ่านกฎรักษาตัวเลข ลิงก์ และคำศัพท์เดิมก่อนนำฉบับแก้ไขมาใช้

เทียบคำแปลจริง 8 ประโยค พร้อมเวลา โทเคน และประมาณค่าใช้จ่าย:

```bash
# ดูชุดประโยคก่อน โดยไม่เรียก API
.venv/bin/python scripts/compare_translation_models.py
# ใช้โควตาจริงของทั้งสองค่าย ต้องมีคีย์ครบก่อนเริ่ม
.venv/bin/python scripts/compare_translation_models.py --live
```

รายงานเริ่มต้นที่ `reports/model-comparison.json` ต้องให้คนประเมินความหมายเอง
ไม่มีการให้คะแนนความแม่นยำอัตโนมัติ ตัวเลขเวลาเป็นการแปลรอบเดียว ไม่รวม OCR
หรือขั้นตอนตรวจความหมายของแอป และราคาประมาณรวมโทเคนการคิดตาม usage ที่ผู้ให้บริการคืนมา
ราคาอ้างอิงตรวจเมื่อ 24 ต.ค. 2026; ควรตรวจใหม่ก่อนประมาณงบจริง

อ้างอิง: [Gemini OpenAI compatibility](https://ai.google.dev/gemini-api/docs/openai),
[Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing),
[Groq models](https://console.groq.com/docs/models)

การตรวจความหมายยังจับคำปฏิเสธ/เงื่อนไขหลายภาษา ราคามัดจำ–ยอดรวม–ยอดคงเหลือ
การเลื่อนเวลา ความไม่แน่นอน และข้อยกเว้น โดยใช้ `translation_risks.py` เป็นตัวเลือกเคส
ไม่ใช่คะแนนความแม่นยำ ภาษาปลายทางมีแนวทางการใช้คำเพิ่มเติมสำหรับฝรั่งเศส เยอรมัน
สเปน เวียดนาม และรัสเซีย การแปลหลายปลายทางใช้การตรวจแบบเดียวกันและหยุดเมื่อจำเป็นต้องถามบริบท
ดูชุดทดสอบจริงและข้อจำกัดได้ที่ [รายงานการปรับคุณภาพ](reports/model-routing/README.md)

### ภาษาถิ่นพร้อมแหล่งอ้างอิง

การแปลปกติยังใช้ข้อมูลศัพท์ตามบริบท เช่น สแลง คำเกม แฟนคลับ และคำพ้องกับอาหาร/
การแพทย์ร่วมกับตัวตรวจความหมาย ดูผลจริงก่อน–หลัง ประโยคใหม่ ภาพ/เอกสาร/เสียง
และข้อจำกัดที่ยังพบใน [รายงานปรับคุณภาพตามบริบท](reports/slang-upgrade/README.md)
ข้อมูลเหล่านี้เป็น reference notes ไม่ใช่การฝึกโมเดล และบางรายการเป็นข้อเสนอ
เชิงบรรณาธิการที่ยังต้องตรวจเพิ่ม เมื่อไม่มีบริบทเพียงพอไม่ควรถือว่าคำแปลแน่นอน

ติดตั้งตัวอย่างคำเมือง–ไทยกลางจากชุดข้อมูลสาธารณะ โดยไม่ต้องใช้คีย์เพิ่ม:

```bash
.venv/bin/python scripts/setup_dialect_references.py
```

ระบบจะสร้างดัชนีค้นหาใน `.data/dialects/` (Git ignore) และใช้ตัวอย่างที่เกี่ยวข้อง
เป็นข้อมูลประกอบการตีความ ก่อนให้ Gemini ตรวจทั้งไทยกลางและภาษาปลายทางเมื่อเปิดใช้งาน
การค้นหาคำเมืองไม่ปนโคราชกับอีสาน หรือปัตตานีกับภาษาใต้ทั่วไป
ไฟล์ติดตั้งตรวจ checksum ของชุดข้อมูลและเก็บที่มา/สัญญาอนุญาต CC BY-SA 4.0

คลังคำสั้นที่มีที่มาถูกแนบใน `data/dialects/curated.json` และช่วยโหมดแปลปกติด้วย
สำหรับคำที่ตรงกัน เช่น เคสคำด่าที่เคยแปลผิด ผู้ใช้เปิดส่วน “แหล่งอ้างอิงที่ค้นพบ”
ในโหมดภาษาถิ่นเพื่อดูตัวอย่างกับลิงก์ต้นทางได้ ตัวอย่างใกล้เคียงไม่ได้ยืนยันความหมาย
ของประโยคใหม่ทั้งหมด และระบบนี้ไม่ได้ฝึกโมเดลภาษาถิ่นใหม่
