# ผลเปรียบเทียบหลังปรับการแปลเป็นประโยค

ทดสอบกับหน้า Google Translate จริงที่แสดง Advanced ใช้ข้อความเดียวกันครบ 26 ข้อ แยกเป็น 12 ข้อเดิมที่ใช้พัฒนาระบบ กับประโยคใหม่ 14 ข้อ ไม่รวมผลทั้งสองชุดเป็นเปอร์เซ็นต์ความแม่นยำ

## ผลที่สังเกต

- **12 ข้อเดิม:** แอปชัดกว่า 4 ข้อ ชัดกว่าแต่มีข้อสังเกตอีก 1 ข้อ และใกล้เคียง 7 ข้อ จุดเดิมเรื่องสำนวน คำถามเหนือ และวันเว้นวันแก้ได้ในรอบนี้ แต่คำแนะนำถูกพัฒนาจากข้อเหล่านั้นโดยตรง จึงเป็นผล regression ไม่ใช่หลักฐานว่ารองรับสำนวน/ถิ่นทั้งหมด
- **14 ประโยคใหม่:** จากการอ่านเทียบโดยผู้ช่วย แอปชัดกว่า 7 ข้อ ใกล้เคียง 5 ข้อ ยังมีปัญหาความหมายทั้งคู่ 1 ข้อ และอีก 1 ข้อทั้งคู่ควรปรับความลื่นไหล ผลนี้ไม่ใช่การประเมิน blind โดยมนุษย์อิสระ และไม่พิสูจน์ว่าแอปเหนือกว่า Google ในภาพรวม
- จุดที่ดีขึ้นชัดคือความหมายของจำนวนที่นั่ง เงื่อนไข การเลื่อนเวลา คำขอสุภาพ การช่วยทำกะ และศัพท์เหนือในประโยคฝน/ตลาด/ร่ม
- จุดที่ยังควรแก้: สำนวนที่ไม่เคยระบุในหมายเหตุ เช่น ลูบหน้าปะจมูก แอปเติมข้อสรุปว่าได้รับ free pass ซึ่งต้นฉบับยังไม่ยืนยัน และการคืนเงินยังใช้คำไทยที่ไม่ลื่นไหล

## สิ่งที่เปลี่ยน

โมเดลยังเป็น gpt-oss-120b เดิม ไม่ได้ฝึกหรือ fine-tune โมเดล เปลี่ยนค่าเริ่มต้นข้อความจาก reasoning low เป็น medium เพื่อให้พิจารณาความหมายก่อนเรียบเรียง เพิ่มคำแนะนำภาษาแบบมีเงื่อนไขและมีข้อความต้นฉบับรองรับ เช่น ความหมายสำนวนเทียบกับอาหารจริง คำถามเหนือ/อีสาน ความถี่ และคำเกริ่นปฏิเสธสุภาพ หมายเหตุไม่ได้เก็บคำตอบทั้งประโยค ระบบ generation และ semantic review เห็นบริบทเหล่านี้ร่วมกัน ซึ่งยังอาจตัดสินผิดร่วมกันได้

ประโยคสมบูรณ์ให้เรียบเรียงเป็นประโยคภาษาปลายทางที่เป็นธรรมชาติ ส่วนวลีที่ยังไม่จบไม่เติมเหตุการณ์เอง การตรวจทานยังป้องกันตัวเลข ลิงก์ ตัวแปร และคลังคำเหมือนเดิม เพิ่มการตรวจเรื่องสำนวน คำถาม และความลื่นไหลที่มีผลต่อความหมาย

ใช้เวลาและโทเคนมากกว่าโหมด low มี rate limit ระหว่างรันชุดเดิมแบบต่อเนื่อง จึงบันทึกข้อผิดพลาดไว้และเว้นช่วงในการทดสอบใหม่ ไม่ตัดสินความแม่นยำของเสียง/ภาพจากผลข้อความนี้

## ทำซ้ำ

```bash
# เปิดแอปเวอร์ชันที่ต้องการทดสอบก่อน แล้วเลือกไดเรกทอรีใหม่เพื่อไม่ทับผลเดิม
LD_LIBRARY_PATH=/tmp/translator-browser-libs/extracted/usr/lib/x86_64-linux-gnu \
node scripts/compare_google_translate.cjs --live \
  --cases reports/google-comparison-v2-sentences/cases.json \
  --out-dir reports/google-comparison-next --pause-ms 12000
```

ต้องมี Playwright/Chromium พร้อม dependencies และใช้โควตา API สคริปต์เก็บภาพ/ผลดิบเพิ่มทีละข้อ `--resume` ทำเฉพาะส่วนที่ยังไม่มีคำแปล `--overwrite` ต้องระบุชัดเจนหากต้องการทับ raw report เดิม ความเห็นเชิงคุณภาพไม่ได้ถูกตัดสินอัตโนมัติจากสคริปต์
