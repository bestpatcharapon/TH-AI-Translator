# เทียบ TH AI Translator กับ Google Translate

เก็บผลเมื่อ 2026-10-23T17:44:21.151Z ถึง 2026-10-23T17:45:04.786Z (UTC)

ผลชุดนี้ยังไม่สนับสนุนว่าแอปเหนือกว่า Google: จากการประเมินของผู้ช่วย Google ชัดกว่า 3 ข้อ แอปชัดกว่า 2 ข้อแต่ยังมีข้อสังเกต ใกล้เคียง 5 ข้อ และมีปัญหาทั้งคู่ 2 ข้อ ไม่มีการคำนวณเปอร์เซ็นต์ความแม่นยำของทั้งระบบ

## วิธีทดสอบ

- ข้อความไทย→อังกฤษ 8 ข้อ และอังกฤษ→ไทย 4 ข้อ กำหนดเกณฑ์ความหมายใน `cases.json` ก่อนเก็บผล
- ใช้ข้อความและคู่ภาษาเดียวกัน ไม่มีคลังคำ คำใบ้ภาษาถิ่น หรือบทสนทนาเพิ่มเติม
- Google: หน้าเว็บจริงแบบไม่ล็อกอิน ทุกภาพแสดงโหมด Advanced ไม่ใช่ผลเดาจากโมเดลอื่นหรือ API proxy
- แอป: API `/api/translate` โหมดข้อความ Natural / General และข้ามแคช ผลที่ได้ใช้การตรวจความหมายตามค่าปัจจุบันของแอป
- โมเดลแอปที่ตั้งไว้: `openai/gpt-oss-120b`; reasoning โหมดข้อความ `low`; Live `medium`
- บันทึก JSON คำขอ/ผล และภาพหน้าจอ Google ครบทั้ง 12 ข้อ ตรวจซ้ำได้จากลิงก์แต่ละแถว
- ผลตัดสินเป็นการอ่านเทียบภาษาโดยผู้ช่วย ไม่มีผู้ประเมินอิสระหรือการทดสอบแบบปิดชื่อผู้ให้บริการ

## ตรวจเพิ่มใน Live Chat

เลือก 5 ข้อที่ยากจากผลด้านบนมาทดสอบหลังเห็นผลแล้ว ใช้ข้อความเดิมโดยไม่มีประวัติ ไม่รวมเข้าไปในยอดสรุปโหมดข้อความ และไม่ได้แก้โค้ดแอประหว่างรอบทดสอบ

| ข้อ | ผลแอป Live | สถานะตรวจความหมาย |
|---|---|---|
| 03-idiom | He/she made it with cilantro sprinkled on top. | checked |
| 07-informal-metaphor | Today my boss dumped so much work on me that I feel dizzy. | checked |
| 08-northern-thai | I've already eaten, okay? | revised |
| 10-polite-refusal | ขออภัย เราไม่สามารถมาคืนนี้ได้ | revised |
| 11-frequency | รดน้ำต้นไม้ทุกวันสลับวัน อย่าให้วันละสองครั้ง. | checked |

Live ช่วยให้คำปฏิเสธสุภาพ (ข้อ 10) เป็นธรรมชาติขึ้น แต่สำนวน ผักชีโรยหน้า คำถามเหนือ และ วันเว้นวัน ยังมีปัญหา สถานะ checked/revised จึงไม่ใช่หลักฐานว่าคำแปลถูกต้อง

## สิ่งที่ควรแก้ต่อ

1. เก็บคำถามภาษาถิ่นเป็นคำถาม และขอความหมายเพิ่มเมื่อไม่รู้คำ ไม่เปลี่ยนคำถามเป็นคำบอกเล่า
2. ตรวจสำนวนในภาษาไทยและความหมายเชิงปฏิบัติ เช่น ผักชีโรยหน้า, หัวหมุน, I’m afraid, every other day
3. ตรวจการเลือกความหมายที่แคบเกินต้นฉบับ เช่น ร้าน → restaurant โดยไม่มีบริบท
4. แยกคำตัดสินของโมเดลตรวจทานออกจากหลักฐานความถูกต้อง และใช้ชุดทดสอบที่ไม่ใช่แค่ตัวเลข/รูปแบบ

## ข้อจำกัด

ตัวอย่างเพียง 12 ข้อ เลือกด้วยมือ ไม่ได้สุ่มจากผู้ใช้จริง และไม่มีการประเมินแบบ blind จึงสรุปอันดับหรือเปอร์เซ็นต์ความแม่นยำโดยรวมไม่ได้ ยังไม่ได้เทียบ OCR ภาพ เสียงไมค์ เอกสารยาว ภาษาอื่น หรือบริบทหลายข้อความ ค่าระยะเวลาใน JSON เป็นคนละช่องทาง (Google เว็บ vs แอป API) จึงไม่ใช้จัดอันดับความเร็ว ผลอาจเปลี่ยนเมื่อผู้ให้บริการเปลี่ยนโมเดลหรือข้อความเปลี่ยน

## ทำซ้ำ

```bash
LD_LIBRARY_PATH=/tmp/translator-browser-libs/extracted/usr/lib/x86_64-linux-gnu \
node scripts/compare_google_translate.cjs --live
```

ต้องเปิดแอปที่พอร์ต 5000 และติดตั้ง Playwright/Chromium พร้อมไลบรารี Linux ก่อน สคริปต์ใช้โควตา API ของแอปและส่งข้อความทดสอบให้ Google ใช้ `--resume` เพื่อเก็บเฉพาะข้อที่ยังไม่มีผล เอกสารผลสดและโหมด Google อยู่ใน `results.json` การตรวจเพิ่ม Live และความเห็นภาษาไทยอยู่ในไฟล์รายงาน ไม่ใช่ผลที่สคริปต์ตัดสินอัตโนมัติ
