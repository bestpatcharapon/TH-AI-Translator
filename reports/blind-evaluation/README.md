# การประเมินแบบปิดตา (blind) เทียบกับ Google Translate

ชุดทดสอบ `tests/data/blind_cases.json` มี 60 ประโยคใหม่ที่ไม่เคยใช้ปรับแอปมาก่อน (ไทย↔อังกฤษ, ภาษาถิ่นเหนือ/อีสาน/ใต้ และไทย↔ลาว พม่า เขมร จีน ญี่ปุ่น เกาหลี เวียดนาม) แต่ละข้อมี `check` บอกเกณฑ์ความหมายที่ผู้ประเมินต้องตรวจ

## ขั้นตอน

1. เปิดแอปใน terminal แยก: `python app.py` (ค่าเริ่มต้น `http://127.0.0.1:5000`) และติดตั้งเบราว์เซอร์ครั้งแรกด้วย `npx playwright install chromium`
2. เก็บคำแปลทั้งสองระบบ (ใช้โควตา API และส่งข้อความไป Google):

   ```sh
   node scripts/compare_google_translate.cjs --live --cases tests/data/blind_cases.json \
     --out-dir reports/blind-evaluation/run-1 --pause-ms 12000
   ```

   ถ้าหยุดกลางทางให้รันซ้ำพร้อม `--resume`
3. สร้างแบบประเมินที่ซ่อนชื่อระบบ (สุ่ม A/B ทุกข้อ และสลับลำดับข้อ):

   ```sh
   .venv/bin/python scripts/blind_evaluation.py prepare \
     --results reports/blind-evaluation/run-1/results.json \
     --out-dir reports/blind-evaluation/run-1/blind --seed 2026
   ```

   ได้ `sheet.csv` (เปิดใน Excel/Google Sheets ได้ ภาษาไทยไม่เพี้ยน) และ `key.json` **ห้ามให้ผู้ประเมินเห็น `key.json`, `results.json` หรือภาพหน้าจอ**
4. ส่ง `sheet.csv` ให้ผู้ประเมิน 2–3 คนที่ไม่ได้เขียนชุดทดสอบ (ควรอ่านทั้งสองภาษาของคู่นั้นได้จริง) แต่ละคนกรอกแยกกัน ไม่ปรึกษากัน:
   - `winner`: `A`, `B`, `tie` หรือ `both_wrong`
   - `meaning_error_A` / `meaning_error_B`: `y` ถ้าผิดความหมายตาม `meaning_criteria`, ไม่ผิดใส่ `n`
   - `notes`: เหตุผลสั้น ๆ; ข้อที่ไม่มั่นใจ (เช่น อ่านภาษาพม่าไม่ออก) ให้เว้น `winner` ว่างไว้
5. รวมผลและเปิดเผยระบบ:

   ```sh
   .venv/bin/python scripts/blind_evaluation.py score \
     --key reports/blind-evaluation/run-1/blind/key.json \
     --ratings rater1.csv rater2.csv rater3.csv \
     --out reports/blind-evaluation/run-1/score.json
   ```

   ได้ผลรายคนและรวม: จำนวนที่แอปชนะ/Google ชนะ/เสมอ/ผิดทั้งคู่, อัตราผิดความหมายของแต่ละระบบ, แยกตามคู่ภาษา, ความเห็นตรงกัน (%) และ Cohen's kappa ระหว่างผู้ประเมินแต่ละคู่ แถวที่เว้นว่างจะถูกนับแยกไว้

## ข้อจำกัด

- ผลดีได้เท่ากับผู้ประเมินและตัวอย่าง: 60 ข้อที่เขียนด้วยมือไม่ใช่ตัวแทนการใช้งานจริงทั้งหมด แต่ละคู่ภาษามีเพียง 3–4 ข้อ จึงสรุปรายภาษาไม่ได้
- ผู้เขียนชุดทดสอบเป็นทีมเดียวกับผู้พัฒนา ประโยคอาจเอียงไปทางที่แอปถนัดหรือไม่ถนัดโดยไม่ตั้งใจ
- Google เป็นเว็บแบบไม่ล็อกอินในวันเวลาที่รัน ผลอาจเปลี่ยนเมื่อรันใหม่ และแอปรันเพียงครั้งเดียวต่อข้อ
- ลีลาภาษาอาจทำให้ผู้ประเมินเดาได้ว่าข้อไหนมาจากระบบใด การปิดตาจึงลดอคติได้ แต่ไม่ได้ตัดออกทั้งหมด
- kappa ต่ำ (ประมาณต่ำกว่า 0.4) แปลว่าผู้ประเมินเห็นไม่ตรงกัน ควรทบทวนเกณฑ์ก่อนเชื่อผลชนะ/แพ้
- ไม่ครอบคลุมรูปภาพและเสียง ดู `data/real-media/README.md` สำหรับการทดสอบด้วยไฟล์จริง
