## บริการจริงหลังแก้

ใช้รูปสังเคราะห์ TXT และเสียง TTS ตัวอย่างเดิม ไม่ใช้ข้อมูลผู้ใช้จริง

- รูปไทย 4 พื้นที่: OCR/แปลสำเร็จ HTTP 200 รักษาราคา 1,250 และประกัน 2 ปี หลังเปลี่ยน optional import ของ Paddle ยังรันโมเดลจริงได้
- เอกสาร: extract และ translate HTTP 200 รักษาใจความยังไม่ได้ซื้อ, 50 ไม่ใช่ 5 คน และการทายาบนแผล
- เสียงสแลงที่ไม่มีคำศัพท์ช่วยยังถอด `ฉันอยู่ 2 ดอมเมนของฉันคือมือกล่อง`; ระบบติดธง `possible_word_confusion` และ benchmark ใหม่หยุดที่ `pending_review` ไม่แปลข้อความผิดนั้นต่อ
- เสียงเดิมเมื่อระบุคำศัพท์ช่วยที่เกี่ยวข้อง `ด้อม, เมน, มือกลอง` ได้ `ฉันอยู่ 2 ด้อมเมนของฉันคือมือกลอง` HTTP 200 กรณีนี้ใช้คำใบ้ที่ทราบจากต้นฉบับ จึงยืนยันได้เพียงว่าคำศัพท์ช่วยกรณีตัวอย่างนี้ ไม่ใช่ผลความแม่นยำทั่วไปหรือการฝึก ASR ใหม่
- เสียงแพ้ถั่วลิสงและค่าโดยสาร 150 ไม่ใช่ 50 ถอด/แปลสำเร็จ HTTP 200 พร้อมคงใจความในตัวอย่างนี้

## ขอบเขตที่ยังต้องตรวจภายนอกเครื่องนี้

คำแปล/การถอดเสียงยังผิดได้ และโควตาหรือบริการภายนอกยังหมด/ล่มได้ การ retry แบบมีขอบเขตช่วยรับมือบางกรณี ไม่ได้กำจัดข้อจำกัดของบัญชีหรือผู้ให้บริการ

ยังไม่มีการ deploy production รอบใหม่ การทดสอบ Safari/โทรศัพท์/ไมค์จริง การทดสอบโหลด production สื่อจริงที่มี ground truth หรือคะแนน blind จากผู้ประเมินอิสระ จึงไม่อ้างว่าใช้งานได้ถูกต้อง 100% ทุกภาษาและทุกสถานการณ์ ผลผ่านทั้งหมดหมายถึงชุดทดสอบที่ระบุข้างต้นเท่านั้น
