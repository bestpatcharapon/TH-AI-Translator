# ทดสอบสแลงและภาษาพูด 100 รายการ

ทดสอบผ่าน Flask `/api/translate` ของแอปที่รันอยู่จริง วันที่ 24 ตุลาคม 2026
ใช้ประโยคไทย → อังกฤษ โทน natural โหมด standard และ `cache_bypass=true`
เรียกตามลำดับ เว้น 2.5 วินาทีระหว่างคำขอ ไม่ได้แก้ logic การแปลระหว่างทดสอบ
ใช้โมเดลและเงื่อนไขเรียกตัวตรวจคำแปลตามการตั้งค่าปัจจุบันของแอป

| กลุ่ม | จำนวน | ความหมายใช้ได้ | ควรปรับรายละเอียด/ภาษา | ความหมายหลักคลาดเคลื่อน |
|---|---:|---:|---:|---:|
| สแลงและภาษาพูดในประโยค | 100 | 67 | 15 | 18 |
| ประโยคความหมายตรงตัว | 12 | 11 | 0 | 1 |
| รวม | 112 | 78 | 15 | 19 |

ตัวเลขนี้เป็นการประเมินเชิงคุณภาพโดยผู้ช่วยเขียนโค้ดเทียบต้นฉบับและ checklist
ที่เขียนก่อนส่งคำขอ ไม่ใช่คะแนนความแม่นยำทั่วไปหรือผลประเมินโดยเจ้าของภาษาแบบ blind
ความหมายที่ใช้ได้ไม่ได้แปลว่าสมบูรณ์แบบ คำที่ขึ้นกับบริบท เช่น นอย/หัวจะปวด
ถูกแยกไว้ในกลุ่มควรปรับ ไม่ฟันธงว่าการอ่านอีกแบบผิดทุกกรณี

## ตัวอย่างที่ผิดชัดเจน

| ต้นฉบับ | ผลจริง | ปัญหา |
|---|---|---|
| คนนี้ของแทร่ | This one belongs to Trae. | กลายเป็นกรรมสิทธิ์ของคนชื่อ Trae |
| มือถือรุ่นนี้กินขาดเรื่องแบตเตอรี่ | The battery on this phone model drains completely. | กลับคำชมว่าแบตเหนือกว่าเป็นแบตหมด |
| ฉันได้หมด | I'm full. | กลายเป็นอิ่มแทนไม่เกี่ยงตัวเลือก |
| เขาพูดช็อตฟีล | he started talking about a short film | สร้างเรื่องภาพยนตร์สั้น |
| โดนแกงแล้ว | I got scolded. | ถูกอำกลายเป็นถูกดุ |
| ทัวร์ลง | the tour was called off | กระแสวิจารณ์กลายเป็นการยกเลิกทัวร์ |
| คนในด้อม | The people in the dorm | แฟนคลับกลายเป็นคนในหอพัก |
| เมนคือมือกลอง | Men is the drummer. | สิ่งที่ชอบที่สุดกลายเป็นชื่อคน |
| ป้ายยาบนแผล | placed a medication label on the wound | ทายากลายเป็นติดฉลากยา |

ตัวอย่างที่ใช้ได้: ตัวตึงเรื่องแก้บั๊ก → the go-to person for fixing bugs,
สาดไปสมาชิก → Go for it, buddy!, อ่อมในบริบทผิดหวัง → falls flat,
ป้ายยาหูฟัง → hyping the headphones จนซื้อ และสมองไหลหลังอ่านโค้ดทั้งวัน →
my brain's fried ส่วนสมองไหลในบริบทย้ายไปทำงานต่างประเทศ → brain drain
ตัวเลข 10/50 กรัม และ 50/5 คนในประโยคควบคุมยังคงถูกต้อง

## ระบบตอบสำเร็จไม่ได้หมายความว่าแปลถูก

- HTTP 200 ครบ 112 คำขอ ไม่มี retry หรือ provider HTTP error ในรอบนี้
- เวลาคำขอค่ากลาง 1.003 วินาที สูงสุด 5.076 วินาที ไม่รวมช่วงพักระหว่างคำขอ
  เป็นการวัดข้อความสั้นบนเครื่องนี้ครั้งเดียว ไม่ใช่ความเร็วรับประกันหรือเวลาหน้าเว็บ
- ระบบไม่ได้เรียก semantic review 79 ประโยค ตรวจแล้วคงเดิม 26 แก้ไข 6
  และผลตรวจใช้ไม่ได้ 1 ประโยค (`หิวแสง`, `invalid_review`)
- ข้อผิดพลาดส่วนใหญ่ไม่มี trigger ให้ตรวจเพิ่ม แต่การมีตัวตรวจไม่ได้รับประกัน:
  `คุยจริงจัง` ยังถูกเปลี่ยนเป็น serious talk แม้มีสถานะ checked และ `ไฟลนก้น`
  ถูก Gemini แก้จาก draft ที่ผิดเป็น My pants are on fire ซึ่งยังเป็นสำนวนที่ไม่เหมาะ
- `สาดไปสมาชิก` มีข้อมูลอ้างอิงที่ผู้ใช้ให้ไว้แล้ว จึงเป็น regression ที่ทราบความหมาย
  ไม่ใช่ตัวอย่างศัพท์ใหม่ที่ระบบไม่เคยมีข้อมูล ทุกคำมีเพียงหนึ่งบริบทและหนึ่งรอบ
  ไม่ได้ครอบคลุมทุกความหมาย คำหยาบ ภาษาถิ่นทั้งหมด เสียงพูด หรือ OCR
- คำชุดนี้มีทั้งสแลงหลายยุคและภาษาพูด ไม่ได้ยืนยันว่าทุกคำเป็นคำฮิตปัจจุบัน
  ไม่ได้เทียบ Google Translate และไม่มีการเพิ่มทั้ง 100 คำเป็นพจนานุกรมในรอบนี้

เพียงรูปแบบเดียว ปัจจุบันยังไม่ได้แก้ข้อผิดพลาดที่พบในรอบนี้

ขณะเปิด `python app.py` อยู่ ใช้คำสั่งนี้เพื่อส่งคำขอจริงใหม่ (ใช้โควตา API):

```bash
.venv/bin/python scripts/benchmark_slang_quality.py --live --output reports/slang-100/rerun.json
```

หากไม่ใส่ `--live` จะแสดงชุดประโยคโดยไม่เรียก API และสามารถใช้ `--resume`
เพื่อทำรายการที่ยังไม่ถูกบันทึกต่อได้ ผลของรอบใหม่อาจต่างจากเดิมแม้ใช้โมเดลเดียวกัน

แนวทางแก้ถัดไป: แยกสแลงออกจากคำพ้องตรงตัวก่อนสร้างคำแปล เพิ่มข้อมูลอ้างอิงที่มีบริบท
สำหรับคำที่ผิด และตรวจด้วยประโยคใหม่ที่ไม่ได้ใช้ปรับระบบ โดยรักษาประโยคอาหาร
การแพทย์ ตัวเลข และการปฏิเสธเป็นชุดกัน regression
